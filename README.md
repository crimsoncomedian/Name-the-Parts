# Name the Parts of an Equation

A multiple choice practice page. Each question shows an addition, subtraction, multiplication or division equation, points at one number, and asks what it is called: addend, sum, minuend, subtrahend, difference, factor, product, dividend, divisor or quotient. Four choices are shown, with a short meaning after a correct answer.

Open `index.html` in a browser, no build step needed.
